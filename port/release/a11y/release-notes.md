## Descargar para jugar (Windows)

**[@ZIP@](@URL@)**

El juego accesible, listo para instalar. Pon este zip junto a tu imagen de disco del juego (el archivo que termina en .iso), extráelo y abre Tenkaichi3Decomp-setup: el instalador habla con tu lector de pantalla. Los pasos están en LEEME.txt, dentro del zip.

El mismo archivo está más abajo, en "Assets". "Source code (zip)" y "Source code (tar.gz)" son el código fuente, que GitHub agrega a cada versión: no sirven para jugar.

Hace falta tu propia imagen de disco de la versión de Estados Unidos (SLUS-21678). No compartas ni pidas imágenes de disco.

## Download to play (Windows)

**[@ZIP@](@URL@)**

The accessible game, ready to install. Put this zip beside your disc image of the game (the file ending in .iso), extract it and open Tenkaichi3Decomp-setup: the setup speaks through your screen reader. The steps are in README-accessibility.txt, inside the zip.

The same file is below, under "Assets". "Source code (zip)" and "Source code (tar.gz)" are the source code, which GitHub adds to every release: they are not what is played.

You need your own disc image of the USA release (SLUS-21678). Do not share or ask for disc images.

## Download to play (Mac with Apple's chip, experimental)

**[@MACZIP@](@MACURL@)**

For Macs with Apple's chip (M1 or later) and macOS 11 or later; on Intel Macs it does not open. It has not been tried on a Mac yet. The game speaks with the Mac's own voice, apart from VoiceOver, and sends no braille. As the program is not signed by Apple, the first time it has to be let through from Terminal: the steps are in README-accessibility.txt, inside the zip.
